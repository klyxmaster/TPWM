TPWM Local Password Manager

A lightweight, privacy-first password manager.

Features
---------
✓ 100% local storage
✓ No cloud
✓ AES encrypted vault
✓ Firefox Click-to-Fill
✓ Password Generator
✓ Secure Notes
✓ Credit Cards
✓ Banking
✓ Import / Export

Installation

1. Download from Mozilla Add-ons.
2. Install.
3. Import your TPWM vault.
4. Enter your master password.
